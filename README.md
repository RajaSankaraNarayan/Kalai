> **KALAI (கலை)** is an active cultural safeguarding and intelligence ecosystem designed to halt the silent extinction of endangered Indian living traditions, mastercrafts, and classical temple iconography. By uniting real-time **Multimodal Gemini Vision AI**, **UNESCO 9-factor diagnostic telemetry**, **Sovereign Tiered Consent**, and **Civic Field Missions**, KALAI bridges thousand-year-old Shilpa Shastras with next-generation artificial intelligence.

---

## 🏛️ Key Innovations & Pillars

### 1. Kalai Lens (Vision AI Grounding)
- **Cultural Relevance Filter**: Intelligently verifies whether an uploaded/captured photo depicts genuine heritage or prompts the user with corrective guidance.
- **Primary GI Database Grounding**: Instant visual matching of registered GI crafts (Pattamadai 120-count silk mats, Aathangudi handmade mineral tiles, Swamimalai lost-wax bronze icons).
- **Open-World Archaeological Intelligence**: Instant identification of uncatalogued temple gopurams, acoustic granite pillars (*Nellaiappar*), and bell castings (*Ariyakudi*) with concise 2-sentence overviews, material traits, and official ASI / Epigraphia Indica source citations.

### 2. UNESCO 9-Factor Vitality Matrix & Concentration Telemetry
- Implements the complete international **UNESCO Intangible Cultural Heritage Vitality Index**.
- Computes dynamic composite health scores ($0-100$) and triggers **Concentration Risk Alerts** when practitioner counts drop below critical sustainability thresholds.

### 3. Gemini Cultural Heritage Scholar & Clean Audio Engine
- Context-grounded conversational agent trained on the Shilpa Shastras, Chola bronze lost-wax proportions (*Dasa Tala* system), and UNESCO Safeguarding guidelines.
- Clean text-to-speech regex pipeline eliminating asterisks, hashes, and markdown syntax for natural spoken prose.

### 4. Sovereign Ethical Consent Protocol & Elder Voice Integrity
- **Tiered Access**: Open Public Archive for global research and tourism vs. Community-Only Protected access for sacred formulas and hereditary guild formulations.
- **Elder Voice Integrity Guarantee**: All elder master oral recordings are preserved and used strictly as they are. Assistive AI narration uses completely separate synthetic non-replicated voices.

### 5. Heritage Rewards (3 Master Tiers)
- Distinctive engraved temple arch badges (**Ancient Elite Tier • 1,000 Pts**, **Chola Sthapati Tier • 750 Pts**, **Royal Guild Tier • 500 Pts**) with 1-click HD export and social sharing.

## 🛠️ Technology Stack

- **Client**: React 18, TypeScript, Vite, TailwindCSS v4, Framer Motion, Web Audio API, Canvas 2D frame capture.
- **Server**: Node.js, Express, TypeScript, REST API (25MB payload limits for raw camera streams).
- **AI / Multimodal**: Google Gemini 3.6 Flash & Gemini 3.7 Flash with strict JSON schema constraints and fallback chaining.
- **Design System**: Neo-Classical Black & Gold Obsidian Sanctuary (`#07080b`, `#fae17d`, `#c89d42`) with authentic vector Kolams, Toda/Kasuti embroidery, Yaazhi temple guardians, and Theyyam masks.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/RajaSankaraNarayan/Kalai.git
cd Kalai
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
PORT=3000
```

### 4. Start the Fullstack Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm start
```
